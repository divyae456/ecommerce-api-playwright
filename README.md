# E-commerce API Automation

API automation framework using:

- TypeScript
- Playwright
- APIRequestContext
- DummyJSON
- Node.js
- npm

## API Base URL

https://dummyjson.com

## Purpose

This project demonstrates REST API automation for an e-commerce application.

The framework will cover:

- GET
- POST
- PUT
- PATCH
- DELETE
- Headers
- Query parameters
- Path parameters
- Request body validation
- Response validation
- Authentication
- Positive scenarios
- Negative scenarios
- Test data management
- Reporting
- Git
- GitHub
- CI/CD
